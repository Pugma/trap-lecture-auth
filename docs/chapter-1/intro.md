# はじめに

皆さんは「認証」「認可」という言葉に馴染みがあるでしょうか？\
traPで開催されている[Webエンジニアになろう講習会](https://traptitech.github.io/naro-text/)では、認証と認可の概略を取り扱っていますが、実装までできる方はそこまで多くないかもしれません\
本テキストでは、認証・認可を基礎から説明し、自分で実装ができるようになることを目指します

## 本テキストの構成 {#structure}

本テキストは以下の章により構成されています\
なお、それぞれの章には座学編・実習編の両方が用意されています

- 第1章: 認証・認可とは
- 第2章: 認可
- 第3章: 認証
- おまけ編①: PasskeyとWebAuthn
- おまけ編②: E2EE (エンドツーエンド暗号化)
